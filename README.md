## 🚀 Quick Start

### 1. Install dependencies
```bash
pip install pandas numpy matplotlib seaborn requests sqlite3
```

### 2. Run the Main Analysis (Day 1)
```bash
cd Day_1/Mini_Project_SuperMart/scripts
python 00_generate_data.py
python supermart_analysis.py
```

### 3. Run Day 3 Labs
```bash
# SQL Lab
python Day_3/Session_1_SQL_for_Data_Analytics/Lab_SQL_Retail.py

# Business Case Lab
python Day_3/Session_2_Business_Case_Study/Lab_Retail_Case_Study.py
```

## 🎯 Day 3 Breakdown

### Session 1: SQL for Data Analytics
- Using **SQLite** to filter and aggregate large datasets.
- Mastering `SELECT`, `WHERE`, `GROUP BY`, and `JOINS`.
- *Lab:* Querying a relational retail database.

### Session 2: Business Case Study
- Identifying **KPIs** (Revenue, AOV, Growth).
- Sales trend analysis and performance benchmarking.
- *Lab:* Solving a retail business challenge for SuperMart.

### Session 3: Data Storytelling
- Turning raw data insights into business decisions.
- Visual narrative techniques and the "Pyramid Principle".
- *Final:* Group presentations on business findings.
