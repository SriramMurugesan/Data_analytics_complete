# Introduction to Power BI & Tableau: Report Creation

## Overview
Once data is connected, the next step is building the visual components of your report. Both Power BI and Tableau use a drag-and-drop interface, making it intuitive to create charts, graphs, and tables.

## Basic Visualizations
- **Bar/Column Charts:** Best for comparing categorical data (e.g., Sales by Region).
- **Line Charts:** Ideal for showing trends over time (e.g., Monthly Revenue).
- **Scatter Plots:** Useful for identifying relationships or correlations between two numerical variables (e.g., Marketing Spend vs. Conversions).
- **Pie/Donut Charts:** Good for showing parts of a whole, but should be used sparingly and only with a small number of categories.
- **Tables/Matrices:** Essential for displaying granular data and detailed metrics.

## Creating Reports in Power BI
1. Navigate to the **Report View** (canvas).
2. From the **Visualizations** pane, click on the icon for the chart type you want.
3. Drag fields from the **Fields** pane into the appropriate buckets (e.g., Axis, Values, Legend) in the Visualizations pane.
4. Format the visual (colors, titles, data labels) using the **Format** tab (the paint roller icon).
5. Arrange multiple visuals on the page to create a cohesive report layout.

## Creating Reports in Tableau
1. Navigate to a new **Worksheet**.
2. Drag fields from the **Data** pane on the left into the **Columns** and **Rows** shelves. 
   - **Dimensions** (blue pills, usually categorical) go to Columns/Rows to define the structure.
   - **Measures** (green pills, usually numerical) go to Columns/Rows to plot the data.
3. Use the **Marks** card to change the chart type, color, size, text, and tooltips.
4. Use the **Show Me** panel in the top right for suggested chart types based on the selected data.
5. Combine multiple Worksheets into a single **Dashboard**.

## Design Principles
- **Keep it simple:** Avoid clutter. Less is often more.
- **Consistent styling:** Use a cohesive color palette and consistent fonts.
- **Clear labeling:** Ensure axes, titles, and legends are easy to read and understand.
- **Tell a story:** Arrange visuals logically so the user's eye flows from high-level metrics to detailed breakdowns.
