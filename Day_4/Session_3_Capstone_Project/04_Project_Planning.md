# Capstone Project: Project Planning

## Overview
A successful analytics project is not just about writing code; it's about executing a plan. The final phase of today's session is to outline your project roadmap from raw data to final presentation.

## Project Phases & Timeline

A typical Capstone Project spans 2-3 weeks. Here is a recommended breakdown:

### Phase 1: Data Preparation & Exploration (Days 1-4)
- **Goal:** Clean data and basic understanding.
- **Tasks:**
  - Load data into database/environment.
  - Handle missing values and duplicates.
  - Perform EDA (Exploratory Data Analysis).
  - Define key metrics to calculate.
- **Milestone:** A clean, merged dataset ready for analysis.

### Phase 2: Deep Dive Analysis (Days 5-9)
- **Goal:** Uncover insights and answer the problem statement.
- **Tasks:**
  - Write complex SQL queries or Python scripts to segment data.
  - Identify trends, correlations, and anomalies.
  - Test hypotheses regarding the business problem.
- **Milestone:** A documented list of 3-5 actionable insights.

### Phase 3: Dashboard Development (Days 10-14)
- **Goal:** Build the interactive visual tool.
- **Tasks:**
  - Import clean data into Power BI / Tableau.
  - Build data model (Star Schema).
  - Create KPIs, Charts, and interactive Slicers.
  - Format for professional presentation.
- **Milestone:** A functional, interactive dashboard.

### Phase 4: Storytelling & Final Presentation (Days 15-18)
- **Goal:** Craft the narrative.
- **Tasks:**
  - Draft the final presentation deck.
  - Translate technical findings into business recommendations.
  - Practice the presentation as a team.
- **Milestone:** Final deck submitted, ready to present.

## Planning Tools
Use a project management tool to track your progress:
- **Trello / Asana / Jira:** Create a Kanban board (To Do -> In Progress -> Review -> Done).
- **Daily Standups:** Have a 10-minute sync with your team every day: "What did I do yesterday? What am I doing today? Are there any blockers?"

## Immediate Next Steps (Today)
Before leaving this session, your team must complete the following:
1. Finalize roles.
2. Set up communication channels.
3. Review the problem statement and dataset.
4. Draft a basic timeline or task list in your chosen project management tool.
